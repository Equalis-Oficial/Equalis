# Equalis

## Sobre
O Equalis é uma plataforma mobile desenvolvida com React Native e MySQL para facilitar a inclusão de pessoas com deficiência (PcD) no mercado de trabalho, contribuindo para a ODS 10 — Redução das Desigualdades. O aplicativo conecta candidatos e empresas, permitindo a divulgação de vagas, a apresentação de qualificações e a busca por oportunidades compatíveis.

## Objetivo
Reduzir as barreiras enfrentadas por pessoas com deficiência durante a busca por emprego, facilitando o acesso a oportunidades profissionais e a comunicação entre candidatos e empresas.
